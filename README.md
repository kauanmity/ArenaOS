## Sua arena. Suas regras.

O ArenaOS une o HaxBall oficial aos recursos da ArenaCup em uma experiência desktop rápida, integrada e feita para partidas competitivas.

| Recurso | Experiência |
| --- | --- |
| **Performance Lab** | FPS, frametime, taxa do monitor, GPU e memória em tempo real. |
| **Match View** | Visual ArenaCup, chat aprimorado, HUD compacto e navegação recolhível. |
| **Hub ArenaCup** | Salas oficiais, perfil, avatar e progressão dos modos competitivos. |
| **Configurações** | Controle de FPS, GPU, baixa latência, Focus Mode e resolução. |
| **Replays** | Biblioteca local automática para suas partidas `.hbr2`. |
| **Atualizações** | Download automático de novas versões pelo canal oficial. |

## Performance sob seu controle

![Performance Lab](https://www.arenacup.com.br/images/arenaos/arenaos-performance.webp)

Escolha entre sincronização com a taxa do monitor e o modo experimental sem limite. Ajuste aceleração por GPU, baixa latência e elementos visuais, acompanhando o impacto diretamente no cliente.

## Feito para jogar

![Partida no ArenaOS](https://www.arenacup.com.br/images/arenaos/arenaos-game.webp)

- Windows 10 e Windows 11, 64 bits.
- Compatível com monitores de alta taxa de atualização.
- Suporte a GPUs NVIDIA, AMD e Intel.
- HaxBall oficial carregado diretamente pelo cliente.

## Instalação

1. Baixe o [instalador mais recente](https://github.com/kauanmity/ArenaOS/releases/latest/download/ArenaCup_Setup.exe).
2. Execute `ArenaCup_Setup.exe`.
3. Conclua o assistente de instalação.
4. Abra o ArenaOS e entre em campo.

> Este repositório é utilizado exclusivamente para distribuir o aplicativo e suas atualizações. O código-fonte do ArenaOS é proprietário e não está disponível publicamente.
